# NUVIA Family Wealth · familia final de tres hojas

Familia de marca derivada del diseño aprobado con tres hojas y un refuerzo muy ligero del tallo derecho de la `N` hasta el nacimiento de las hojas.

Esta carpeta contiene la identidad activa del portal. La familia anterior de cinco hojas se conserva únicamente como archivo histórico.

## Recomendaciones de uso

- Usar las versiones transparentes sobre fondos claros y limpios.
- Usar la versión invertida o las aplicaciones azul, verde o negra sobre fondos oscuros.
- Mantener espacio libre alrededor del símbolo equivalente, como mínimo, a la altura de una hoja lateral.
- Para tamaños pequeños, utilizar los iconos ya exportados y evitar reducir directamente el logotipo completo.
- No alterar la proporción, el número de hojas, el grosor del tallo ni la relación entre símbolo, nombre y descriptor.
