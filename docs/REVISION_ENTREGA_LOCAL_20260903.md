# NUVIA · Revisión de procedencia y entrega local

Fecha: 03-09-2026. Continuación autorizada: «más».

## Incidencia comprobada

La cabecera de Cartera todavía afirma que los fundamentales utilizan una
«instantánea local». La aplicación ya consulta la base propia al elegir una
empresa y distingue un respaldo local cuando no puede verificar la consulta.
El texto exterior no describe el funcionamiento actual.

Se corregirá únicamente esa explicación y se ampliará el ensayo de instalación
limpia para incluir las pruebas actuales de cartera, modelos y fundamentales.
No se modifican datos, cálculos, funciones, permisos ni fuentes. No se publica.

## Revisión previa · marco §12

1. Necesidad: explicar la procedencia real y verificar una entrega reproducible.
2. Entradas: archivos locales existentes y datos ficticios de las pruebas.
3. Transformación: texto informativo y ampliación de verificaciones locales.
4. Resultado: consulta a base propia, respaldo identificado y ausencia de tiempo real.
5. Emisores: los existentes; no se añaden ni seleccionan otros.
6. Circunstancias personales: no se utilizan.
7. Conducta inversora: no se recomienda operar ni mantener posiciones.
8. Valor futuro: no se incorporan previsiones de PER, BPA ni dividendos.
9. Atractivo inversor: no se ordenan ni puntúan instrumentos.
10. Recomendaciones ajenas: no se reproducen.
11. Interfaz: aclaración de procedencia; ninguna retirada ni bloqueo nuevo.
12. Acciones: se conservan los controles de consulta existentes.
13. Remuneración: sin cambios.
14. Separación profesional: trabajo exclusivo sobre NUVIA Portal Lab.
15. Datos personales: ninguno nuevo; cero escrituras en la base de datos.
16. IA: no se incorpora generación de contenido en la web.
17. Fuentes: funcionamiento de App.jsx y remote.js, sin afirmar actualización continua.
18. Regresión: contrato del aviso en fuente y paquete, pruebas de carga y respaldo,
    instalación limpia, comparación de huellas y revisión en escritorio/tablet.

Clasificación del ajuste de texto: información objetiva; no reclasifica el módulo
de empresas ni sustituye su ficha. Verificación interna, no validación jurídica.
