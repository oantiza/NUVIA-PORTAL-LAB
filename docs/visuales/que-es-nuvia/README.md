# Visuales de «¿Qué es NUVIA?»

Fuentes editables y exportaciones visuales basadas en
`docs/DEFINICION_NUVIA.md` y en la página `que-es-nuvia.html`.

Las exportaciones se regeneran con `scripts/generate-que-es-nuvia-visuals.py`.

## Piezas

- `infografia.html` / `infografia-que-es-nuvia.png`: síntesis vertical 1620 × 2880.
- `storyboard.html` / `storyboard-que-es-nuvia.png`: recorrido audiovisual en
  ocho escenas y 52 segundos, construido con fotogramas exactos de la página,
  2880 × 1620.
- `pagina-completa-que-es-nuvia.png`: captura de la página real en escritorio,
  1265 × 7471, ensamblada a partir de tramos de pantalla para evitar
  repeticiones.

## Estado

Material de comunicación editable, sujeto a retoques finales. La definición
canónica continúa siendo `docs/DEFINICION_NUVIA.md`.

## Prueba regulatoria resumida

- Necesidad: explicar de manera visual la naturaleza educativa de NUVIA.
- Datos y transformación: solo contenido institucional ya aprobado; no recibe
  datos del usuario ni realiza cálculos.
- Instrumentos, personalización y decisión: no incluye instrumentos concretos,
  perfiles, veredictos, recomendaciones, contratación ni derivación comercial.
- Lenguaje y presentación: distingue de forma expresa información, explicación
  y decisión; conserva el descargo educativo.
- Clasificación: **verde**.
