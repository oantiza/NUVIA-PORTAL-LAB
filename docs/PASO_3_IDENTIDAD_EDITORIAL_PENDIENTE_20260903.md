# Paso 3 · Identidad pública y responsabilidad editorial

Fecha: 03-09-2026.

## Decisión del fundador

Este paso queda aplazado. Los datos se mantienen sin completar hasta que el
fundador decida qué información debe indicarse y autorice su publicación.

| Dato | Estado |
|---|---|
| Identidad pública o titular | **Pendiente de indicar** |
| Canal público de contacto | **Pendiente de indicar** |
| Persona o equipo responsable de la revisión editorial | **Pendiente de indicar** |

## Aplicación durante la alfa

- No se inventan, deducen ni publican nombres, direcciones o datos de contacto.
- No se muestran campos vacíos ni la expresión «Pendiente de indicar» en la web
  visible al visitante; el estado se conserva únicamente en la documentación
  interna del proyecto.
- No se guarda información personal en la base de datos para completar este paso.
- El punto permanece abierto para una decisión posterior y no bloquea el
  desarrollo de la alfa.
- La selección editorial existente continúa con su funcionamiento actual. La
  designación formal de una persona o equipo responsable queda pendiente.

## Condición para reabrir el paso

El paso se retomará cuando el fundador facilite o confirme expresamente los datos,
su redacción pública y el alcance de su publicación. Hasta entonces se conserva el
estado actual sin cambios en la interfaz, la base de datos ni el despliegue.
